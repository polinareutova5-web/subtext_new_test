# Универсальная платформа частного преподавателя

Шаблон содержит только ученический личный кабинет. Одна установка подключается к одной Google-таблице и одному предмету. Кабинета преподавателя и многопредметной структуры нет.

- `config.js` — название бренда, цвета, URL Apps Script.
- `222.js` — `SPREADSHEET_ID`, `SUBJECT_KEY`, `SUBJECT_LABEL`.
- `НАСТРОЙКА.md` — инструкция по настройке и заполнению таблицы.

Преподаватель управляет данными напрямую в Google Sheets. Для каждого покупателя нужны собственные таблица и Apps Script deployment.
